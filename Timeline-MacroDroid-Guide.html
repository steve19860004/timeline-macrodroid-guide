iQOO 15 陸版 · OriginOS · V2505A

一鍵恢復 Google 地圖時間軸

用 MacroDroid 搭配 Shizuku，讓地圖在 640 dp 下啟動，再恢復原本的畫面大小。先設桌面捷徑，測通後再加每日排程。

首次設定桌面一鍵每日定時還原與排錯

先確認手機條件

這份腳本按實測手機的數值撰寫：陸版 iQOO 15、主使用者、有效解析度寬 1440 像素、原廠密度 640 dpi、日常最小寬度 360 dp。其他機型請勿照抄密度值。

640 dp 和 640 dpi 指的是不同數值。這支手機把密度暫改為 360 dpi，最小寬度才會變成 640 dp。開始前到開發人員選項，截圖記下自己的「最小寬度」。

在手機啟動 Shizuku

  1. 安裝 MacroDroid 和 Shizuku，連上 Wi-Fi，開啟開發人員選項中的「無線偵錯」。
  2. 首次使用時，從 Shizuku 點「配對」，再到無線偵錯點「使用配對碼配對裝置」，把配對碼輸入 Shizuku 的通知。
  3. 回 Shizuku 點「啟動」，等首頁顯示服務正在執行。首次透過 MacroDroid 執行時，允許它使用 Shizuku。

重開機後：免 Root 的無線偵錯模式需要再次啟動 Shizuku。一般只需首次配對；先確認服務運作，再點捷徑或等排程。

建立桌面一鍵捷徑

  1. 開 MacroDroid →「新增巨集」，命名為「恢復 Google 時間軸」。
  2. 點「觸發器」的 ＋，搜尋「捷徑」或 Shortcut Launched，選「捷徑啟動」。
  3. 點「動作」的 ＋，用放大鏡搜尋英文 Shell Script。這個項目在「動作」裡；選取後，將執行方式設為 Shizuku。如果看不到這個選項，先更新 MacroDroid。
  4. 把下方整段貼進腳本欄，確認並儲存巨集。直接貼手機 Shell 語法，不用加 PowerShell 或 adb shell。
  5. 長按手機桌面空白處 →「小工具／捷徑」→ MacroDroid → 選擇巨集捷徑 →「恢復 Google 時間軸」。桌面名稱依啟動器而異；若建立觸發器時已出現「加到主畫面」，可直接加入。
# iQOO 15 陸版 V2505A，直式、日常最小寬度 360 dp
set -eu
stop() { echo "$*" >&2; exit 1; }
[ "$(id -u)" = 2000 ] || stop "請將執行方式選為 Shizuku"
[ "$(getprop ro.product.model)" = V2505A ] || stop "此範例只供 V2505A"
[ "$(am get-current-user)" = 0 ] || stop "請切回手機主使用者"
case "$(am get-config)" in
  *-sw360dp-*) ;;
  *) stop "請先確認日常最小寬度為 360 dp" ;;
esac
size=$(wm size | tail -n 1 | awk '{print $NF}')
[ "${size%x*}" = 1440 ] || stop "目前解析度不符合範例"
density=$(wm density)
physical=$(echo "$density" | sed -n 's/^Physical density: //p')
original=$(echo "$density" | sed -n 's/^Override density: //p')
[ "$physical" = 640 ] || stop "此機的原廠密度不同"
case "$original" in ''|640) ;; *) stop "日常顯示密度不同";; esac

lock=/data/local/tmp/iqoo15-timeline-run
mkdir "$lock" 2>/dev/null || stop "已有執行紀錄，請看網頁的還原說明"
changed=0
finish() {
  if [ "$changed" = 1 ]; then
    wm density "${original:-reset}" || { echo "還原失敗，請手動恢復 360 dp" >&2; return 1; }
  fi
  rmdir "$lock"
}
trap finish EXIT
trap 'exit 1' HUP INT TERM
maps=com.google.android.apps.maps
service=com.google.android.gms
activity=$(cmd package resolve-activity --brief --user 0 -a android.intent.action.MAIN -c android.intent.category.LAUNCHER -p "$maps" | tail -n 1)
case "$activity" in "$maps"/*) ;; *) stop "找不到 Google 地圖";; esac
changed=1
wm density 360
sleep 2
case "$(am get-config)" in *-sw640dp-*) ;; *) stop "未切到 640 dp";; esac
am force-stop --user 0 "$maps"
am force-stop --user 0 "$service"
am start -W --user 0 -n "$activity"
sleep 6

第一次按下捷徑

先解除鎖定、停在桌面，並結束正在進行的導航。腳本會暫時縮小介面，依序強制停止 Google 地圖、Google Play 服務，再開啟地圖。等畫面恢復原大小後，點帳號頭像 →「你的時間軸」。回到開發人員選項確認最小寬度已回到 360 dp。

想驗證自動記錄，正常帶手機出門後，隔天選昨天的日期，確認實際停留的地點有出現。

在同一個巨集加入每日排程

  1. 編輯「恢復 Google 時間軸」，在「觸發器」再按 ＋，搜尋「日期／時間」或 Day/Time Trigger。
  2. 勾選週一到週日，選自己通常已解鎖、也沒有導航的時間，例如每天 08:30。兩個觸發器採「任一符合」即可，共用原來的腳本。
  3. 在「限制條件」加入「裝置已解鎖」或對應的 Device Locked/Unlocked 條件，選已解鎖。儲存並啟用巨集。
  4. 首次測試可設成兩分鐘後，保持手機解鎖。確認地圖啟動、畫面還原，再改回日常時間。
時間到了若手機鎖定，這次排程會略過。解鎖後可點桌面捷徑補跑。地圖原本正常時，只留捷徑即可，避免每天中斷正在使用的 Google 服務。

沒反應，或畫面沒有還原？

捷徑沒動作

看 Shizuku 首頁是否顯示執行中，再到「已授權應用程式」確認 MacroDroid 已獲允許。回巨集檢查 Shell Script 的執行方式，並看 MacroDroid 系統日誌。若要單獨驗證權限，可在測試動作執行 id -u 並查看輸出，無線偵錯模式應是 2000。

桌面可用，定時沒有執行

在巨集的系統日誌查該時間是否觸發、是否被鎖定條件略過。若完全沒有觸發，確認巨集已啟用、日期時間正確，再查看手機對 MacroDroid 的背景執行限制。

畫面卡在 640 dp，或提示已有執行紀錄

腳本會在正常結束或一般錯誤時還原；強制結束程序或突然重開機仍可能中斷。先等腳本停止，在「開發人員選項 → 最小寬度」填回截圖中的原值（本例 360 dp）。確認沒有其他巨集正在執行後，若仍提示已有執行紀錄，在 Shizuku 模式的 Shell Script 單獨執行 rmdir /data/local/tmp/iqoo15-timeline-run，再點捷徑。

畫面已還原，但仍無法使用時間軸

先確認本機用手動 640 dp 流程能開啟時間軸。這份巨集重現開啟地圖的流程，各系統版本、啟動耗時及背景記錄結果仍須實機驗證；備份和造訪記錄要另外確認。
